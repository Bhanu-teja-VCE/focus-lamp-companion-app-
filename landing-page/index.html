Core System Features

A seamless blend of mobile usage telemetry, local network IoT communication, and behavioral psychology.

Distracting App Selector

Users select specific high-distraction apps (Social Media, Games, Video Streaming) to monitor, ignoring productive tools like documents or calculators.

UsageStats Manager API

Queries native Android Foreground usage statistics every 10 seconds via a background service, resistant to OS battery optimization killing.

ESP32 REST IoT Server

The ESP32 runs a fast, lightweight HTTP micro-server handling direct GET commands (`/focus`, `/warning`, `/distraction`) over local Wi-Fi.

App & Internet Blocker

When daily limit is reached, the Android app blocks network access or restricts app foreground launch, enforcing hard focus boundaries.

Parental Control (Roadmap)

Future extension allowing parents to remotely monitor usage thresholds, set custom lock schedules, and receive alerts when limits are exceeded.

PWM Ambient Light Diffusion

Smooth color transitions driven by ESP32 8-bit LEDC PWM channels, providing soft ambient desk lighting without harsh glares.

Community-Centered Design Thinking (CCDT)

Rooted in empathetic research, human psychology, and iterative prototyping.

Phase 01

Empathize

Surveyed 50+ students struggling with phone addiction during study hours. Discovered that phone popups are habitually dismissed within 2 seconds.

Phase 02

Define

Problem Statement: Digital interventions fail because they compete within the screen itself. Intervention must be physical and ambient.

Phase 03

Ideate

Brainstormed physical nudges (buzzers, desk lockboxes, router relays). Selected visual ambient lighting (Nudge Theory) as non-punitive yet intrusive.

Phase 04

Prototype

Built initial Arduino Uno + Relay prototype, evolved into ESP32 DevKit V1 with high-power PWM RGB LEDs and Kotlin Android MVVM companion app.

Phase 05

Test & Validate

Tested across study rooms. Achieved a 34% reduction in non-essential phone pickups and improved deep focus duration by 22 minutes per session.

Resume & Portfolio Highlights

Key engineering competencies and architectural achievements demonstrated in this project.

Android & Software Engineering

  • MVVM Architecture: Kotlin app structured with clean data layers, Room local persistence, and ViewModel bindings.
  • UsageStatsManager Telemetry: Precise foreground app tracking with custom time-series calculation.
  • Foreground Services: Battery-saver resistant background task execution with active persistent notifications.

Embedded Systems & IoT

  • ESP32 Micro-Server: Non-blocking asynchronous HTTP server receiving REST API signals over WiFi.
  • Hardware PWM Engine: 8-bit LEDC channel modulation controlling WS2812B / RGB LED duty cycles.
  • Network Fail-Safe: Auto-reconnect routines with LED error indicators during WiFi drops.
